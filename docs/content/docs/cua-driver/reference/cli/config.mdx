### `opensky-driver config set`

Set one config key.

Cursor motion defaults are saved keys that apply to sessions started afterwards: cursor.motion.style (signature_arc, spring_settle, magnetic, comet_swoop, adaptive, classic), cursor.motion.timing (native, fitts, fixed) and cursor.motion.effects.&lt;trail|glow|magnet|ripple|squish&gt; (true, false). Use null for a key to clear it, or cursor.motion null to clear all. A start_session cursor_motion or a set_agent_cursor_motion call overrides the saved default.

```text output
opensky-driver config set <key> <value>
```

| Argument | Type | Default | Description |
| --- | --- | --- | --- |
| `<key>` | string | required | Config key to write. |
| `<value>` | string | required | Value to store. |

**Examples**

```bash test="cli-shape" id="ref-opensky-driver-config-set"
# Downscale screenshots to at most 1568 px
opensky-driver config set max_image_dimension 1568

# Make magnetic the default cursor motion for new sessions
opensky-driver config set cursor.motion.style magnetic

# Scale cursor move time with distance and target size
opensky-driver config set cursor.motion.timing fitts

# Turn the cursor trail on by default
opensky-driver config set cursor.motion.effects.trail true
```

## `opensky-driver cursor`

Configure a session's agent cursor from the command line.

Forwards to the set_agent_cursor_motion tool on the running daemon. Fields you leave out keep their current value.

```text output
opensky-driver cursor <COMMAND>
```

**Examples**

```bash test="cli-shape" id="ref-opensky-driver-cursor"
# Use the magnetic cursor motion
opensky-driver cursor motion --session demo --style magnetic
```

### `opensky-driver cursor motion`

Set the cursor's motion style, timing and effects.

Effects take on, off, or default (the style's own choice).

```text output
opensky-driver cursor motion [OPTIONS]
```

| Flag | Type | Default | Description |
| --- | --- | --- | --- |
| <span id="opensky-driver-cursor-motion--session"></span>`--session` | string | required | Public label of the session that owns the cursor. |
| <span id="opensky-driver-cursor-motion--style"></span>`--style` | string |  | signature_arc, spring_settle, magnetic, comet_swoop, adaptive, or classic. |
| <span id="opensky-driver-cursor-motion--timing"></span>`--timing` | string |  | native, fitts, or fixed. |
| <span id="opensky-driver-cursor-motion--effects"></span>`--effects` | string |  | Comma-separated name=on\|off\|default for trail, glow, magnet, ripple, squish. |
| <span id="opensky-driver-cursor-motion--glide-ms"></span>`--glide-ms` | number |  | Move duration in milliseconds for fixed timing (1430 when 0). |
| <span id="opensky-driver-cursor-motion--socket"></span>`--socket` | path |  | Override the daemon socket path. |

**Examples**

```bash test="cli-shape" id="ref-opensky-driver-cursor-motion"
# Use the comet swoop cursor motion
opensky-driver cursor motion --session demo --style comet_swoop

# Make every move take 900 ms
opensky-driver cursor motion --session demo --timing fixed --glide-ms 900

# Turn off the trail and reset the click ripple
opensky-driver cursor motion --session demo --effects trail=off,ripple=default
```

## Exit codes

| Code | Meaning |
| --- | --- |
| `0` | Success. |
| `1` | Failure: the daemon is not running or is incompatible, a tool call returned an error, or the operation failed. `call` and direct tool invocations exit with the daemon's result code (1 on a tool error); `update --apply` passes through the installer's status. |
| `2` | Invalid input: tool arguments that are not valid JSON, an unknown `mcp-config` client, or an `update --apply` refused on a local development install. |
| `64` | Usage error: an unknown or missing subcommand or argument, or conflicting flags (for example `revoke` without exactly one of `--session` or `--all`, or an authorization flag passed to `mcp`). |
